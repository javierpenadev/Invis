# Invis

Клон InviZible Pro (Android) для Windows: **Tor + DNSCrypt-proxy + I2Pd** под одним
управлением. Electron-приложение с трее: маленькое окно, живые статусы модулей,
настройки автозапуска.

- Источник идеи: [InviZible Pro](https://github.com/Gedsh/InviZible) (GPL-3.0)
- Демоны — официальные сборки: Tor Expert Bundle, dnscrypt-proxy, i2pd

## Приложение (`app/`)

```bash
cd app
npm install
npm run fetch-bins   # один раз: скачать демонов в bin\ (~87 МБ, SHA-256 архивов сверяются)
npm start
```

Сборка релиза: `npm run dist` → `npm run checksums` → приложить `release/SHA256SUMS.txt`
к релизу (без него авто-обновление у пользователей не ставится — сверка целостности
обязательна). Готовые сборки — в [Releases](https://github.com/javierpenadev/Invis/releases).

Подробнее — [app/README.md](app/README.md): структура, tray-поведение,
настройки, точки расширения.

## Статус (v1.9.5)

Работает: запуск/мониторинг Tor/DNSCrypt/I2Pd; **перехват системного DNS**
(адаптеры → 127.0.0.1, dnscrypt на :53, нужны права администратора, восстановление
при выходе и после сбоев, детект занятого порта 53); **системный прокси на Tor**
(`socks=127.0.0.1:9050` — Chrome/Edge и все WinINET-приложения, localhost/LAN мимо
Tor). Галки DNS/прокси — намерения: остановка модулей снимает только эффект,
настройка сохраняется и применяется при следующем запуске. Мосты Tor (obfs4/conjure),
выбор стран выхода с подсказками Onionoo, «Сменить IP» + автосмена, резольверы
(авто/ручной выбор из public-resolvers), пресеты блок-листов с автообновлением,
диагностика, скорость канала (шапка + трей), IP выхода с городом и пингом,
авто-обновление с проверкой SHA-256, tray со статусами, автозапуски, бэкап DNS/прокси.
Рендерер изолирован (contextIsolation + preload-мост с allowlist каналов).
Дальше по плану: kill switch, экран логов, TUN-режим.
